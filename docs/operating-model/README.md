# Operating Model Documents

This folder is the canonical shared layer for agent behavior.

Start with `docs/workflow/core-bootloader.md`; load only task-triggered core sources. Relevant documents:

1. `AGENT_OPERATING_MODEL.md`
2. `SKILL_CATALOG.md` — optional editorial discovery aid, not a required inventory
3. `AGENT_EVALUATION_CHECKLIST.md`
4. Existing workflow rules such as `dynamic-routing.md`, `role-definitions.md`, `quality-gates.md`, and `handoff-contract.md`

Recommended rule:

- Before routing work, read the operating model.
- Select applicable available skills from discovered descriptions; consult the catalog only when useful. Missing skills fall back to base-role/core requirements without waiving gates.
- Before completing work, run the evaluation checklist.
