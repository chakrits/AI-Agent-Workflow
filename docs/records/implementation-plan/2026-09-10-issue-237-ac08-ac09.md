# Implementation Plan — Issue #237 AC-08/AC-09

## Objective

Collapse the detailed skill catalog entries into the approved five-column selection table while preserving all 31 skill triggers, owners, exclusion boundaries, and next-step routing. Update the six catalog-heading assertion cases so they verify row presence instead of stale `## <skill>` headings.

## Scope

- Replace the detailed 31-skill blocks with one `Skill | Trigger | Primary Agent | Do Not Use When | Next Skill / Agent` row per skill.
- Apply the same shape to `Current Skills` and `Engineering Discipline`.
- Keep the Planned Skills and explanatory notes intact.
- Add a structural contract test covering all 31 rows, five cells, non-empty chaining, and removal of stale skill headings.
- Repin `required-source-matrix.json` for the catalog edit.

## Risks and rollback

The catalog is a pinned source file and is consumed by contract/context validators. The source-matrix repin is part of the change. Rollback is a revert of the atomic catalog/test/matrix commit; no runtime or adapter behavior changes.

## Handoff

Developer self-review follows this plan. Independent QA must re-derive row completeness and policy preservation from ADR-0023 and verify the mutation probes before PR creation.
